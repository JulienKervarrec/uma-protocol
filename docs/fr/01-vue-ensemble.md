# 1. Vue d’ensemble d’UMA

UMA fournit des oracles optimistes pour publier puis contester des données sur Ethereum. Le protocole suppose qu’une proposition honnête n’est pas contestée, tout en prévoyant un mécanisme de résolution lorsque deux parties divergent.

Le monorepo regroupe les contrats, les clients SDK, les outils de déploiement et plusieurs packages applicatifs. Le parcours se concentre sur l’Optimistic Oracle, le DVM et les composants qui les relient.

L’oracle ne transforme pas une donnée externe en vérité automatique : il organise un marché d’assertions, de bonds, de délais et de litiges.
