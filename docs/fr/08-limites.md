# 8. Limites et périmètre

Ce parcours couvre les assertions UMA, les bonds, les délais, les disputes, le DVM, Finder, les whitelists, les variantes d’oracle, le SDK et les bots de surveillance.

Il ne constitue ni un audit, ni une preuve que les paramètres actuels sont adaptés, ni une validation des déploiements réseau. La sécurité dépend de la gouvernance, du mécanisme de vote, des hypothèses économiques et de l’intégration aval.

Aucune installation, compilation, exécution de test ou transaction n’a été effectuée. Le contenu repose sur la lecture statique du README, des packages optimistic-oracle, core et sdk. Consultez les tests du dépôt pour poursuivre.

Retour au [sommaire](README.md).
