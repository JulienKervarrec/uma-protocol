# 6. Versions, Skinny Oracle et SDK

Le monorepo contient plusieurs générations de l’Optimistic Oracle ainsi qu’un Skinny Optimistic Oracle. Les interfaces et états ne sont pas interchangeables sans adapter les paramètres et les événements.

Le SDK expose des clients, des types d’état et des machines pour proposer, contester, régler et surveiller les requêtes. Il aide à orchestrer les transactions mais ne remplace pas la vérification des contrats et du réseau.

Les tests du SDK montrent les parcours attendus et les erreurs traitées. Cette documentation les cite comme orientation ; aucune suite n’a été exécutée pendant ce parcours.
